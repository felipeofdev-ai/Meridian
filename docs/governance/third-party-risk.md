# Third-Party Risk Policy

## Critical Dependencies
- Cloud hosting provider
- Managed database provider
- Identity provider (Okta/Azure AD)
- Logging/monitoring vendors

## Risk Assessment
- Security posture review before onboarding
- Annual reassessment for critical vendors

## Vendor Onboarding Process
1. Security questionnaire
2. DPA and legal review
3. Access scope minimization
4. Continuous monitoring registration
