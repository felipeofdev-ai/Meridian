# Deployment Tiers

## Tier A — SaaS Multi-tenant
Shared control plane with tenant isolation enforced by app + DB policies.

## Tier B — Dedicated Tenant
Dedicated compute and data plane per customer with managed operations.

## Tier C — Full Isolated (Single-tenant VPC)
Customer-specific VPC/account/subscription with isolated networking and key domains.

## Tier D — Air-gapped Mode
Offline/on-prem deployment with controlled update channels and local signing/verifier workflows.
