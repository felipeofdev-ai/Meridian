# Integration Architecture

## GitHub Enterprise
- Webhooks + REST/GraphQL APIs
- HMAC webhook validation

## GitLab
- Webhooks + API v4
- Token-based webhook verification

## ServiceNow
- Incident and control ticket export via REST API

## Splunk
- Security/audit log forwarding via HTTP Event Collector

## Okta
- OIDC/SAML SSO for enterprise authentication
