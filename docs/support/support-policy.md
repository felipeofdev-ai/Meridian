# Support Policy

## Version Support Window
- Major versions: supported for 24 months
- Minor versions: supported for 12 months
- Patch releases: security and critical fixes only

## Support Tiers
- Standard: business-hours support
- Enterprise: 24x7 support with priority SLAs

## Security Patch SLA
- Critical: patch or mitigation within 72h
- High: within 7 days
- Medium/Low: next scheduled patch cycle
